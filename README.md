# Speech-Recognizer-Transcriber-tool
A simple Python-based project that converts speech to text using Google’s Web Speech API. It listens to audio input from the microphone and transcribes it in real time, adjusting for ambient noise and handling common errors like unintelligible speech. To view the output kindly download the RAW file.
Files -
1. Code File - Speechrec.py
2. Output File- Speech recognizer_Final Output (2).mp4
